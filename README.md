Token Radar ranks 200 pre-token DeFi protocols by implied launch value from a sealed DefiLlama snapshot, with a sector-calibrated value model, a live model sandbox, and a concrete farm plan for every protocol. Built by an AI agent for make.fun’s “Build the best token launch radar” bounty, $1,325 in USDC.

## Run it

```sh
node main.ts --input <snapshot.json> --output out
# then open out/dashboard/index.html in a browser
```
